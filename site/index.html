A reading list
with an end.

RSS Boi is a self-hosted RSS reader. It shows the posts you subscribed to, newest first, until you're all caught up.

Run it with Docker View on GitHub

Docker Compose · PostgreSQL · installable web app · MIT licensed

Set for long reads

Articles open in Literata at a comfortable measure, with scripts stripped out. Work through a list with j and k, and turn single-key shortcuts off if they clash with speech input or a screen reader.

Add it to your phone's Home Screen and the app icon carries your unread count.

A polite poller

Every check sends ETag and If-Modified-Since, so an unchanged feed costs the publisher almost nothing. A feed that keeps failing backs off on its own, up to an hour between tries.

daringfireball.net/feeds/main304 not modified
sixcolors.com/feed3 new entries
example.org/rssretrying in 8 min

Every feed on its own schedule

Check a busy news site every five minutes and a monthly newsletter once a day. Keep a noisy feed out of All, Today and Unread so it only shows up on its own page.

See why a feed broke

RSS Boi keeps the last response status, content type and body for every feed, so a failing subscription shows you what the server actually sent.

Keep what you read

Save any article as a PDF, or download every image in a post as a ZIP. Move your subscriptions between servers with a JSON export.

Three containers and a database

A React web app, a Fastify API and a background worker, backed by PostgreSQL. Everyone in the house can have their own account and read state. Feed fetches to private addresses are blocked by default, and you can allowlist just the hosts you trust.

# web, api and worker, backed by postgres
$ docker compose ps
NAME       IMAGE                              STATUS
web        ghcr.io/bevanjkay/rss-boi:web      Up (healthy)
api        ghcr.io/bevanjkay/rss-boi:api      Up (healthy)
worker     ghcr.io/bevanjkay/rss-boi:worker   Up
postgres   postgres:16-alpine                 Up (healthy)

# poll an RSSHub instance on your LAN, and nothing else private
ALLOW_PRIVATE_HOSTS=192.168.86.199:1200

Install

curl -fsSLO https://raw.githubusercontent.com/bevanjkay/rss-boi/main/docker-compose.yml
curl -fsSL https://raw.githubusercontent.com/bevanjkay/rss-boi/main/.env.example -o .env
docker compose up -d

Set SESSION_SECRET and the database password in .env before the first start. Then open http://localhost:3000, name your server and create the admin account.

Why run your own

A reader on your own server can't be shut down, sold or turned into a recommendation engine. Your subscriptions and read history stay in your own database.
